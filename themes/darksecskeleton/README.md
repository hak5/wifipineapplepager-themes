# Darksec Skeleton

An orange LCD theme for the WiFi Pineapple Pager on firmware 2.0.0-stable. The
dashboard adapts the Flipper Zero's monochrome menu to the Pager's display and
controls. The dashboard, lock screen and startup sequence use original
pixel-art skeleton artwork. This theme includes the Pager's menus, dialogs,
status bars, keyboards and screen assets.

## Install

Copy the `darksecskeleton` directory into `/mmc/root/themes/` or `/root/themes/`
on the Pager:

```text
/root/themes/darksecskeleton/
├── theme.json
├── components/
└── assets/
```

Then select **Darksec Skeleton** under **Settings → General → Theme**.

The Pager LCD base is Pocket Pager by Korben.

- [Hak5 Pocket Pager](https://github.com/hak5/wifipineapplepager-themes)
