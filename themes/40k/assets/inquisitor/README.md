# INQUISITOR 40K — Reference-matched visual assets

This asset pack uses the **exact image supplied by the user** as its artistic foundation. All full-screen images are 480 × 222 pixels. It includes six dashboard selection states, six functional-section visual mockups, ten system-screen treatments, icons, a palette, and an asset manifest.

## Compatibility and installation
This is an **asset pack**, not a confirmed installable theme. The Hak5 Pager requires `theme.json` and compatible component JSON definitions. Do not install this folder directly as a theme. Map these assets into a firmware-matched official theme using Hak5 Theme Studio or compatible theme editor. The radial wheel is a set of selectable visual states, **not a tested working D-pad wheel**. The pictured menu text is baked into PNGs and the underlying Pager actions are not changed by these images.
