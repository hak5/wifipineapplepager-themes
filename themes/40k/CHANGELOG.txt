INSTALL
Back up the working theme. Extract and copy only the inquisitor_40k folder to /root/themes/ or /mmc/root/themes/, replacing the old theme folder after backing it up. Select INQUISITOR 40K and reload the UI. The review folder is for your computer, not the Pager.
