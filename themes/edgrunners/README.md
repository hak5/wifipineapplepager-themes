EDGRUNNERS — 3.0.0 / NIGHT CITY DISTRICTS EDITION

INSTALL
Extract edgrunners.zip into /root/themes/ or /mmc/root/themes/ so the file is directly at edgrunners/theme.json. Reload the theme list and select edgrunners. Back up your previous edgrunners folder first; this revision replaces it.

DESIGN / CHANGES
- Complete 205-asset custom visual set, with an editable SVG and a 4x PNG export for every native asset.
- Three new high-resolution scene illustrations: rooftop Recon, neon Payloads workshop and orbital Portal; distinct section artwork and newly drawn filled multicolor dashboard icons.
- Restored readable tutorial lettering on the dark message box.
- Text-fit fixes: repositioned all five Portal Recon payload rows, capped long dialog headers and Recon labels, bounded client signal/interface columns. Checked 472 selectable states with normal data and 472 with long labels, including SVG lettering. Offline font metrics are approximate; final hardware verification remains necessary.
- Six-sector circular main menu, exact-size label sprites, detailed neon icons, layered selector wedges, chrome hub and circuit marks.
- Six keyboard modes with metallic keycaps, clear labels and matching neon focus overlays; original key definitions and actions retained.
- Coordinated dialogs, YES/NO buttons, status indicators, signal levels, toggle states, folders, arrows, warnings, upgrade screens and locks.
- Boot: 12 frames; loading: 12 frames at 120ms; launch: 6 frames. Uses existing animation-array schema. Real firmware memory/performance and timing remain untested.
- Custom documentation, license and virtual-Pager screens; QR rectangles including quiet zones are pixel-identical to the supplied codes.
- Native 480x222 screen assets and original small-asset sizes for installation. 4x SVG-rendered exports are editing masters, not firmware assets. The original QR code within HD exports is a scaled raster, not newly invented QR detail.

OPTIONAL ART
Nine wallpapers (three scenes in clean, circuit and glitch styles) and three alternate dashboard backgrounds. These are outside the installable theme. To use an alternate dashboard, copy optional-dashboard-art/<scene>.png over assets/dashboard/wargames_bg_updated.png in the installed theme. Do not copy the @4x version.
