# Edgerunners Detail Glitch

A Cyberpunk: Edgerunners Pager theme with the revised detail/glitch artwork set, six-button dashboard, all six keyboard modes, explicit YES/NO confirmation artwork, payload banners, lock screens, loading animations and status-state graphics.

## Author

sinXne0

## Firmware

Built for WiFi Pineapple Pager firmware 2.0 using theme framework 0.9.

## Description

Includes 135 component definitions and 167 PNG assets sized for the 480 x 222 Pager display. All component, asset, palette and template references resolve within the theme folder. Original Hak5 component base.

## Installation

Copy the `edgerunners_detail_glitch` folder to `/root/themes/` or `/mmc/root/themes/`, then select **edgerunners_detail_glitch** under Settings → General → Theme.
