# Darkseclabz Numeric

A WiFi Pineapple Pager theme modeled on a 1990s alphanumeric pager. It uses a
recessed olive LCD with segmented menu numbers, a charcoal pager case, an
inbox-style payload menu, and a self-test animation at startup.

## Install

Copy the `darkseclabz-numeric` directory into `/mmc/root/themes/` or
`/root/themes/` on the Pager:

```text
/root/themes/darkseclabz-numeric/
├── theme.json
├── components/
└── assets/
```

Then select **Darkseclabz Numeric** under **Settings → General → Theme**.

The theme targets Pager firmware 2.0.0-stable and uses the menu definitions and
supporting assets of Korben's Pocket Pager theme from the Hak5 theme repository.
The dashboard, lock screen, boot animation and payload inbox artwork are custom.

- [Pocket Pager source](https://github.com/hak5/wifipineapplepager-themes)
